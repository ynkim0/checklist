# 오늘의 할 일 체크리스트

오늘 할 일을 적고, 끝낸 일을 체크하는 한 페이지짜리 웹입니다. 서버 없이 브라우저만으로 동작하며, 목록은 브라우저 localStorage에 저장됩니다.

## 기능

- 할 일 추가 (Enter 또는 추가 버튼)
- 완료 체크 (취소선과 흐린 색으로 표시)
- 항목 삭제
- 새로고침해도 유지되는 자동 저장
- 진행률 표시 (예: 3/5 완료)

## 실행

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 배포 (GitHub Pages)

저장소 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하면 배포됩니다.

## 구성

- `index.html` 화면 구조
- `style.css` 스타일 (다크 모드 지원)
- `app.js` 동작과 저장
